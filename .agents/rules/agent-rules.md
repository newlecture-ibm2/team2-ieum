# 이음 프로젝트 AI 에이전트 코딩 가이드라인 워크플로우

1. **프로젝트 환경 파악**
   - 프로젝트명: 이음 (ieum) - 전국 지역 축제 정보 제공 플랫폼
   - 주 목표: 축제 정보 제공 및 커뮤니티 기반의 Next.js 웹 애플리케이션

2. **기술 스택 규칙 적용**
   - 프레임워크: Next.js 16.x (App Router 기반)
   - 라이브러리: React 19.x, TypeScript (정적 타입 검증 강화)
   - 전역 상태 관리: Zustand
   - 데이터 통신: Axios
   - 세션 및 인증: iron-session
   - 아이콘: lucide-react

3. **기본 코딩 컨벤션 준수**
   - **타입스크립트 활용**: `any` 타입의 사용을 피하고 반드시 `interface`나 `type`을 활용해 타입을 세밀하게 정의한다.
   - **렌더링 최적화**: 서버 컴포넌트(Server Component)를 기본으로 활용하고 인터랙션이 필요한 부분만 최상단에 `"use client"`를 명시해 클라이언트 컴포넌트로 분리한다.
   - **모듈화**: 컴포넌트와 유틸리티 함수를 재사용 가능하도록 나누어 캡슐화한다.
   - **패키지 관리**: 작업 중 새로운 npm 패키지가 필요하다면 무단으로 설치하지 않고 사전에 사용자에게 도입 이유를 설명한 뒤 동의를 받는다.

4. **수정 및 디버깅 가이드라인 적용**
   - **코드 보호**: 리팩토링이나 새로운 기능을 추가할 때 기존 로직이 망가지지 않도록 주의한다.
   - **생략 최소화**: 코드를 출력할 때는 생략(`// ...`)을 최소화하여 사용자가 그대로 복사/붙여넣기 할 수 있게 돕는다. (단, 100줄 이상 매우 긴 파일은 정확한 수정 위치 전후를 표기한다.)
   - **사전 계획 리포팅**: 본격적인 코드 수정 전, 어떻게 구현을 풀어나갈 것인지 간단한 이유(Reasoning)를 제시한다.
   - **에러 분석 철저**: 오류 발생 시 단순 추측을 피하고, 에러 로그를 분석하여 근본적인 원인을 파악해 수정안을 제시한다.
