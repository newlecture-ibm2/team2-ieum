## 1. 개요

### 1-1. 목적
이 문서는 프로젝트의 모든 API 엔드포인트를 **컨트롤러 단위**로 묶고, 각 컨트롤러가 호출하는 **서비스(UseCase)** 목록을 정리합니다.

### 1-2. 설계 원칙
- **헥사고날 아키텍처**: Controller → UseCase(Port IN) → Service → Port OUT → Adapter
- **공통 응답 포맷**: 모든 API는 `ApiResponse<T>` 형태로 응답
- **인증**: Spring Security + JWT, 비회원/회원/관리자 3단계 권한

### 1-3. API ID 규칙

> **팀 공통 규칙**: `API_{도메인코드}_{4자리 순번}`

| 도메인 코드 | 영역 | 설명 |
|------------|------|------|
| `AUTH` | 인증 | 회원가입, 로그인, 회원탈퇴 |
| `USR` | 사용자 | 프로필 관리, 알림, 마이페이지 |
| `FES` | 축제 | 축제 조회, 검색, 지도, 스크랩 |
| `REV` | 리뷰 | 리뷰/별점 CRUD |
| `CAL` | 달력 | 달력 기반 축제 조회 |
| `BRD` | 게시판 | 게시글/댓글 CRUD |
| `NTC` | 공지사항 | 공지 조회, 첨부파일 |
| `INQ` | 문의사항 | 문의 등록 |
| `RPT` | 신고 | 신고 접수 |
| `ADM` | 관리자 | 대시보드, 축제관리, 신고, 공지, 문의 |

### 1-4. 공통 응답 포맷

```json
// 성공
{ "success": true, "data": { ... }, "error": null }

// 실패
{ "success": false, "data": null, "error": { "code": "AUTH_001", "message": "인증이 필요합니다" } }

// 페이징
{ "success": true, "data": {
    "content": [ ... ],
    "page": 1, "size": 10, "totalElements": 150, "totalPages": 15
  }, "error": null }
```

### 1-5. 공통 헤더

| 헤더 | 값 | 필수 | 설명 |
|------|-----|------|------|
| `Content-Type` | `application/json` | ✅ | 요청/응답 형식 |
| `Authorization` | `Bearer {JWT}` | 🔒 회원/관리자 | 인증 토큰 |

### 1-6. 인증 레벨 범례

| 표기 | 의미 |
|------|------|
| ✅ 비회원 | 인증 없이 접근 가능 |
| 🔒 회원 | JWT 필수 (role=USER) |
| 🔐 관리자 | JWT 필수 (role=ADMIN) |

### API_AUTH_0010: 로그인 처리 (JWT 발급)

| 항목 | 내용 |
|------|------|
| **API ID** | API_AUTH_0010 |
| **엔드포인트** | `POST /api/auth/login` |
| **UseCase** | `LoginUseCase` |
| **Service** | `AuthService.login()` |
| **인증** | ✅ 불필요 |
| **담당자** | 우혁 |

**Request Body:**
```json
{ "email": "user@example.com", "password": "Password123!" }
```

**Response (200):**
```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": { "userId": 1, "email": "user@example.com", "nickname": "축제러버", "role": "USER" }
  }
}
```

**에러:** 401 이메일 또는 비밀번호 불일치

### API_AUTH_0020: 회원가입 처리 (유효성 검증 포함)

| 항목 | 내용 |
|------|------|
| **API ID** | API_AUTH_0020 |
| **엔드포인트** | `POST /api/auth/register` |
| **UseCase** | `RegisterUseCase` |
| **Service** | `AuthService.register()` |
| **인증** | ✅ 불필요 |
| **담당자** | 우혁 |

**Request Body:**
```json
{
  "name": "홍길동",
  "email": "user@example.com",
  "nickname": "축제러버",
  "phone": "010-1234-5678",
  "password": "Password123!",
  "passwordConfirm": "Password123!",
  "termsAgreed": true,
  "marketingAgreed": false
}
```

**유효성 검사:**

| 필드 | 규칙 |
|------|------|
| name | 2~20자, 한글/영문 |
| email | 이메일 형식, 중복 불가 |
| nickname | 2~20자, 중복 불가 |
| phone | 010-XXXX-XXXX 형식 |
| password | 8~20자, 영문+숫자+특수문자 조합 |
| passwordConfirm | password와 일치 여부 |
| termsAgreed | 필수 약관 동의 여부 (true 필수) |

**Response (201):**
```json
{ "success": true, "data": { "status": "SUCCESS" } }
```

**에러:** 400 유효성 실패 / 409 이메일·닉네임 중복

## 13. Spring Security URL 패턴 설정

```java
// SecurityConfig.java — URL별 인가 규칙 요약
http.authorizeHttpRequests(auth -> auth
    // ✅ 인증 불필요 (비회원 허용)
    .requestMatchers(HttpMethod.POST, "/api/auth/**").permitAll()
    .requestMatchers(HttpMethod.GET, "/api/festivals/**").permitAll()
    .requestMatchers(HttpMethod.GET, "/api/reviews/**").permitAll()
    .requestMatchers(HttpMethod.GET, "/api/calendar/**").permitAll()
    .requestMatchers(HttpMethod.GET, "/api/community/posts").permitAll()       // 커뮤니티 목록만 비회원 허용
    .requestMatchers(HttpMethod.GET, "/api/community/posts/popular").permitAll() // 인기글 비회원 허용
    .requestMatchers(HttpMethod.GET, "/api/community/categories").permitAll()   // 카테고리 비회원 허용
    .requestMatchers(HttpMethod.GET, "/api/community/search").permitAll()       // 검색 비회원 허용
    .requestMatchers(HttpMethod.GET, "/api/notices/**").permitAll()
    
    // 🔒 회원 전용
    .requestMatchers("/api/users/me/**").hasRole("USER")
    .requestMatchers(HttpMethod.GET, "/api/community/posts/*").hasRole("USER") // 커뮤니티 상세는 회원 전용 (목록→상세 진입 시 회원가입 유도)
    .requestMatchers(HttpMethod.POST, "/api/reviews").hasRole("USER")
    .requestMatchers(HttpMethod.PATCH, "/api/reviews/**").hasRole("USER")
    .requestMatchers(HttpMethod.DELETE, "/api/reviews/**").hasRole("USER")
    .requestMatchers(HttpMethod.POST, "/api/festivals/*/scrap").hasRole("USER")
    .requestMatchers(HttpMethod.POST, "/api/community/**").hasRole("USER")
    .requestMatchers(HttpMethod.PUT, "/api/community/**").hasRole("USER")
    .requestMatchers(HttpMethod.PATCH, "/api/community/**").hasRole("USER")
    .requestMatchers(HttpMethod.DELETE, "/api/community/**").hasRole("USER")
    .requestMatchers(HttpMethod.POST, "/api/reports").hasRole("USER")
    .requestMatchers(HttpMethod.POST, "/api/users/me/fcm-token").hasRole("USER")
    .requestMatchers(HttpMethod.POST, "/api/inquiries").hasRole("USER")
    
    // 🔐 관리자 전용
    .requestMatchers("/api/admin/**").hasRole("ADMIN")
    
    // 🔒 그 외 인증 필요
    .anyRequest().authenticated()
);
```
