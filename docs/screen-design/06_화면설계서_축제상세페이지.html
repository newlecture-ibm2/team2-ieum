🎯 Event Description
E1 찜하기 토글 (Toggle Bookmark)
· 트리거: 🤍 아이콘 클릭
· 비로그인: 로그인 유도 팝업
· 로그인 시: 찜 상태 토글 (🤍 ↔ ❤️)
· API: POST /api/festivals/{festivalId}/scrap
E2 리뷰 작성 (Submit Review)
· 트리거: [리뷰 등록] 버튼 클릭
· 전제: 로그인 + 별점 선택(1~5) + 내용 입력(10~500자)
· 동작: 리뷰 등록 + 리뷰 목록 및 통계 즉시 갱신
· 제한: 축제당 1인 1리뷰
· API: POST /api/festivals/{festivalId}/reviews
E3 별점 선택 (Select Rating)
· 트리거: 리뷰 작성 폼의 ★ 아이콘 클릭
· 동작: 클릭한 별까지 노란색으로 채움 (1~5점 선택)
E4 리뷰 수정/삭제 (Edit/Delete Review)
· 트리거: 본인 리뷰의 [수정] / [삭제] 텍스트 클릭
· 수정: 인라인 편집 모드 전환 → PATCH 요청
· 삭제: 확인 모달 → DELETE 요청
· API: PATCH /api/reviews/{commentId}, DELETE /api/reviews/{commentId}
E5 리뷰 페이지네이션 (Review Pagination)
· 트리거: 리뷰 목록 하단 ◀ 1 2 3 ▶ 클릭
· 동작: 해당 페이지 리뷰 데이터 재조회
· API: GET /api/festivals/{festivalId}/reviews?page={page}
E6 페이지 진입 시 자동 조회수 증가 (View Count)
· 트리거: 상세 페이지 최초 로드
· 동작: viewCount +1 증가 (세션 기반 중복 방지)

Check Point

· 조회 시 viewCount +1 증가 (세션 기반 중복 방지)
· 로그인 시 isScrapped 필드로 찜 상태 반영
· 북마크 클릭 → API_FES_0040 토글 호출
· 후기 작성 시 10~500자 / 별점 1~5 필수
· 본인 리뷰만 수정(PATCH)/삭제(DELETE) 가능
· 축제당 1인 1리뷰 제한
