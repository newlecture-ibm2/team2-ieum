Description

Summary.

  • 모든 페이지 상단에 고정되는 공통 네비게이션 바
  • 브랜드 로고, 주요 메뉴, 알림/마이페이지 접근 제공
  • 현재 페이지에 해당하는 메뉴에 퍼플 밑줄로 활성 상태 표시
  • 스크롤 시 상단에 고정 (sticky)
1 브랜드 로고
· 핑크→퍼플 그라데이션 핀 아이콘 + "이음" 텍스트
· 클릭 시 홈 (메인 페이지)으로 이동
· 축제 위치를 상징하는 지도 핀 모티브
2 메인 네비게이션 메뉴
· 전국축제 - 진행중/진행전/지도 탭으로 분기
· 지난축제 - 종료된 축제 아카이브
· 달력 - 월별 축제 캘린더 뷰
· 커뮤니티 - 게시판 (목록: 전체, 상세: 회원)
· 공지 - 공지사항 목록
현재 활성 페이지에 퍼플 밑줄 + 볼드 표시
3 알림 아이콘
· 벨 아이콘 클릭 시 알림 목록 드롭다운 또는 페이지 이동
· 읽지 않은 알림이 있을 경우 빨간 점(dot) 뱃지 표시
· 회원 전용 기능 (비회원 시 로그인 유도)
4 마이페이지 아이콘
· 퍼플 원형 사용자 아이콘
· 클릭 시 마이페이지로 이동
· 비로그인 상태에서는 로그인/회원가입 페이지로 이동
· 로그인 상태에서는 프로필/즐겨찾기/내 게시글 등 접근
🎯 Event Description
E1 로고 클릭 (Navigate to Home)
· 트리거: 이음 로고 영역 클릭
· 동작: 메인 홈페이지(전국축제)로 라우팅 이동
E2 네비게이션 메뉴 클릭 (Menu Navigation)
· 트리거: 전국축제/지난축제/달력/커뮤니티/공지 클릭
· 동작: 해당 페이지로 라우팅 이동 + 클릭된 메뉴에 active 스타일 적용
· 시각적 피드백: 퍼플 밑줄 + 볼드 표시
E3 알림 아이콘 클릭 (View Notifications)
· 트리거: 벨 아이콘 클릭
· 동작: 알림 목록 드롭다운 표시 또는 알림 페이지 이동
· 비회원: 로그인 페이지로 리다이렉트
· 읽지 않은 알림 존재 시 빨간 dot 뱃지 표시 (FCM 연동)
E4 마이페이지 아이콘 클릭 (Navigate to Mypage / Login)
· 트리거: 사용자 아이콘 클릭
· 로그인 상태: 마이페이지(즐겨찾기)로 이동
· 비로그인 상태: 로그인/회원가입 페이지로 이동
E5 스크롤 시 헤더 고정 (Sticky Header)
· 트리거: 페이지 하단 스크롤
· 동작: position: sticky로 상단 고정 + 미세 그림자 추가

Check Point

· 헤더는 모든 페이지에서 동일하게 렌더링 (공통 컴포넌트)
· 스크롤 시 상단에 고정 (position: sticky)
· 현재 URL에 따라 활성 메뉴 자동 하이라이트
· 반응형: 모바일에서는 햄버거 메뉴로 변환 고려
· 알림 뱃지는 실시간 FCM 연동

Description

Summary.

  • 전국축제, 지난축제, 커뮤니티, 공지사항에서 공통으로 사용되는 검색/필터/정렬 UI
  • 페이지별로 Type A / B 중 선택하여 적용
  • 통일된 라운드 스타일, 퍼플 액센트 컬러
1 검색 입력바 (공통)
· 돋보기 아이콘 + placeholder 텍스트
· 배경: #f8f9fa, 라운드 8px
· Enter 또는 검색 버튼 클릭 시 검색 실행
2 검색 버튼
· 퍼플 그라데이션 배경
· 돋보기 아이콘 + "검색" 텍스트
3 필터 버튼 (Type A)
· 클릭 시 필터 모달/드롭다운 표시
· 퍼플 배경 (활성 시)
· 페이지별 필터 항목:
· 전국축제: 지역, 카테고리, 기간
· 지난축제: 지역, 연도, 카테고리
· 커뮤니티: 카테고리(전체/후기/질문/정보공유/자유)
4 활성 필터 태그
· 선택된 필터를 pill 태그로 표시
· ✕ 초기화 버튼으로 한번에 제거
5 정렬 드롭다운 (공통)
· 최신순이 기본 선택
· 페이지별 옵션 상이:
· 축제: 최신순/인기순/이름순
· 공지: 최신순/조회순
· 커뮤니티: 최신순/인기순/댓글순
6 검색 유형 선택 (Type B)
· 전체 / 제목 / 내용 선택 가능
· 공지사항 페이지 전용
7 검색 버튼 (Type B)
· 검색 유형 + 키워드로 필터링
8 정렬 (Type B)
· 최신순 / 조회순
🎯 Event Description
E1 검색 실행 (Execute Search)
· 트리거: 검색 버튼 클릭 또는 Enter 키 입력
· 동작: 입력된 키워드로 API 호출 + 결과 목록 즉시 갱신
· 제한: 최소 2자 이상, 특수문자 sanitize
E2 필터 모달 열기/닫기 (Toggle Filter)
· 트리거: [필터] 버튼 클릭
· 동작: 필터 모달/드롭다운 표시 ↔ 숨김 토글
· 필터 적용 시 결과 목록 + 카운트 동적 갱신
E3 필터 태그 제거 / 초기화 (Clear Filter)
· 트리거: 개별 태그 ✕ 또는 [초기화] 클릭
· 동작: 해당 필터 해제 + URL 쿼리 파라미터 업데이트 + 목록 갱신
E4 정렬 변경 (Change Sort Order)
· 트리거: 정렬 드롭다운 선택 변경
· 동작: 선택된 정렬 기준으로 목록 재정렬 + URL 파라미터 업데이트

Check Point

· 검색/필터/정렬은 URL 쿼리 파라미터로 관리 (?search=&sort=&filter=)
· 필터 변경 시 결과 목록 및 카운트 동적 갱신
· 빈 결과 시 "검색 결과가 없습니다" 안내 표시
· 검색어는 최소 2자 이상, 특수문자 sanitize 처리
