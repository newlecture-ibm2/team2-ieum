Description

Summary.

  • 일반 소통, 축제 관련 질문(Q&A), 꿀팁, 먹거리 리뷰 등을 위한 커뮤니티 공간
  • 조회수나 추천수가 높은 인기글을 상단에 별도 노출하여 활발한 소통 유도
  • 게시글 검색 및 최신순/조회순/공감순 필터링 지원
  • 무한 스크롤(Infinite Scroll) 방식을 통한 자연스러운 피드 소비
1 네비게이션 탭
· 전국축제 등 공통 GNB 헤더 적용
· '커뮤니티' 탭이 현재 활성화 상태(보라색)로 표시됨
2 검색바 내 필터 드롭다운 (다중 조건)
· 검색 인풋 옆 [필터] 버튼 클릭 시 드롭다운 팝업 형태의 필터 패널 노출
· 필터 세부 항목 : ① 말머리(Q&A, 꿀팁, 리뷰 등) ② 지역 ③ 기간 선택
· 복합 필터 조건 선택 후 [필터 반영하기] 시 커뮤니티 리스트 비동기 업데이트
3 공통 검색창 & 정렬 옵션
· 커뮤니티 내 작성된 게시글 제목/본문 기반으로 통합 검색
· 우측 드롭다운: 최신순, 조회순, 공감순 정렬 지원
4 인기 게시글 영역 (Top 3)
· 최근 24~48시간 이내 좋아요 수가 가장 높은 게시물 3개를 하이라이트 노출
· 아이콘/랭킹 번호 등으로 일반 게시글과 차별화
5 일반 게시글 리스트
· 각 게시글마다 카테고리 태그 표기 (Q&A: 보라, 꿀팁: 초록, 리뷰: 노랑 배지 적용)
· 텍스트 위주 리스트이나 썸네일 존재 시 우측에 표기
6 글쓰기 플로팅 액션 버튼(FAB)
· 🔒 로그인 한 사용자에게만 노출 (비로그인 회원은 숨김 처리)
· 클릭 시 커뮤니티 글 작성 에디터 페이지로 이동

Check Point

· 카테고리 탭 및 이벤트 필터 변경 시 전체 페이지 리로드 대신 컴포넌트 비동기(AJAX) 리렌더링
· 검색바에서 엔터키 입력 시 검색 이벤트 바인딩 필수
· 서버사이드 무한 스크롤 구현을 위한 Intersection Observer 연동 예정
