Description

Summary.

  • 일반 소통, 축제 후기, 동행 구하기 등을 목적으로 하는 커뮤니티 게시판
  • 조회수나 추천수가 높은 인기글을 상단에 노출하여 활발한 소통 유도
  • 무한 스크롤(또는 페이징)을 통한 전체 및 탭별 게시글 목록 제공
1 상단 헤더
· '커뮤니티' 타이틀 표시
· 우측 상단 검색 아이콘 🔍 클릭 시 커뮤니티 전용 게시글 검색 화면으로 이동
· 알림 아이콘 내 새로운 소식 뱃지 표시
2 카테고리 탭 영역
· 전체 | 자유게시판 | 축제후기 | 동행구함 등 주제별 탭
· 탭 클릭 시 해당 분류에 속하는 게시글만 리스트에 실시간 필터링
· 현재 활성화된 탭은 폰트 두껍게 혹은 언더라인으로 시각적 구분
3 인기 게시글 영역 (Top3 등)
· 최근 24시간~7일 이내 일정 기준의 좋아요/댓글 수를 달성한 게시글 노출
· 피드로 가로 스와이프(수평 스크롤) 또는 상단 배너/카드 형태로 배치
4 일반 게시글 리스트
· 탭 필터링 결과 최신순 정렬 노출
· 정보 포함 내용: [카테고리명] 글 제목, 본문 미리보기(1~2줄 요약), 이미지 썸네일(첨부 시)
· 정보 포함 현황: 좋아요(공감) 수, 댓글 수 아이콘 표시
5 글쓰기 플로팅 액션 버튼(FAB)
· 우측 하단 펜 모양 플로팅 영역 고정
· 스크롤을 내려도 항상 같은 위치를 유지하며 클릭 시 커뮤니티 '글 작성 페이지'로 이동
· (비로그인 사용자 클릭 시 로그인 팝업 호출)
6 하단 GNB 네비게이션
· 홈 / 전국축제 / 커뮤니티 / 마이페이지 등 앱 주요 이동 동선
· '커뮤니티' 탭이 현재 활성화 상태 파란색으로 표시

Check Point

· 카테고리 탭 이동 시 전체 페이지 리로드 대신 목록 영역만 비동기(AJAX) 데이터 갱신
· 게시물 목록 무한 스크롤 구현 (최하단 도달 전 page+1 자동 로드)
· 최신 순, 좋아요 순 등 정렬 옵션 고려 (필요시 Select Box 추가 배치)
