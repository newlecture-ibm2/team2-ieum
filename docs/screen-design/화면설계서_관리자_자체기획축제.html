Description

Summary.

  • 관리자가 직접 기획한 축제를 등록·수정·삭제하는 CRUD 화면
  • 축제 목록 테이블 + 등록/수정 폼 제공
  • API_ADM_0040~0043 연동
  • 좌측 사이드바로 관리자 메뉴 전환
1 관리자 사이드바 네비게이션
· 현재 메뉴(자체기획 축제)는 파란색 활성 표시
· 다른 관리 메뉴 클릭 시 해당 화면으로 전환
2 페이지 타이틀 + 서브텍스트
· "🎪 자체 기획 축제 관리" 제목
· 관리자(ADMIN) 권한 전용
3 "+ 축제 등록" 버튼
· 클릭 시 하단 등록 폼 표시 (또는 모달)
· 파란색 버튼으로 강조
4 자체 기획 축제 목록 테이블
API: GET /api/admin/festivals/custom (API_ADM_0040)
· 컬럼: 축제명, 지역, 날짜, 카테고리, 상태, 관리
· 축제명 클릭 → 상세 / 수정 모드 진입
· ✏️ 수정 / 🗑️ 삭제 관리 액션
5 축제 등록/수정 폼
등록 API: POST /api/admin/festivals/custom (API_ADM_0041)
수정 API: PUT /api/admin/festivals/custom/{id} (API_ADM_0042)
· 필드: 축제명, 지역, 시작일/종료일, 상세내용, 대표이미지
· 등록 시 title, content, img 전송
· 수정 시 기존 데이터 pre-fill
6 삭제 기능
API: DELETE /api/admin/festivals/custom/{id} (API_ADM_0043)
· 🗑️ 클릭 시 확인 모달 표시
· 확인 후 해당 축제 삭제 처리
· 삭제 성공 시 목록에서 즉시 제거

Check Point

· 관리자(ADMIN) 권한 검증 필수
· 축제명, 날짜는 필수 입력 — 미입력 시 클라이언트 유효성 검사
· 이미지 업로드는 multipart/form-data 사용
· 삭제 시 실제 DB 삭제 (공공축제와 달리 하드 삭제)
· 수정 시 기존 이미지 유지/변경 선택 가능

📡 Related API
API ID Method Endpoint 설명 파라미터 인증
API_ADM_0040 GET /api/admin/festivals/custom 자체 기획 목록 조회 page, size 🔐 관리자
