Summary.

  • 월별 캘린더로 축제 일정을 한눈에 조회하는 페이지
  • 날짜별 축제 개수 표시, 날짜 클릭 시 해당일 축제 카드 리스트 노출
  • 비회원도 조회 가능 (API_FES_0005)

Home | National Festivals | Festival Calendar | Map
현재 선택 탭 "Festival Calendar"에 활성 표시
2 페이지 타이틀
"Monthly Festival Calendar" 고정 타이틀
페이지 진입 시 현재 월 자동 표시
3 월 이동 네비게이션
"2026.3" 연월 표시 + ◀ ▶ 화살표
클릭 시 이전/다음 월로 이동, API 재호출 (year, month 파라미터)
4 캘린더 요일 헤더
일~토 요일 표시 (보라색 배경)
일요일: 빨간색, 토요일: 파란색 텍스트
5 날짜 셀 (축제 개수 표시)
각 날짜에 해당 일에 진행중인 축제 개수 표시
오늘 날짜: 보라색 원형 배경으로 하이라이트
날짜 클릭 시 하단 ⑦ 축제 리스트 갱신
6 축제 개수 카운트
start_date~end_date 범위에 해당 날짜가 포함되면 카운트
0개인 날짜는 카운트 미표시
7 선택 날짜 축제 카드 리스트
선택한 날짜의 축제를 가로 스크롤 카드로 표시
카드 구성: 대표이미지, 축제명, 위치, 기간, 진행상태 태그, 해시태그, [상세보기] 버튼
[상세보기] 클릭 → /festivals/{id} 상세 페이지 이동
3개 초과 시 가로 스크롤 또는 "더보기" 처리

Check Point

· FullCalendar 라이브러리 활용 (monthView)
· API: GET /api/festivals/calendar?year=2026&month=3
· 축제 기간(start~end)이 복수 날짜에 걸치면 각 날짜에 모두 카운트
· 날짜 미선택 시 오늘 날짜 축제를 기본 표시
· 카드 클릭 시 /festivals/{festivalId}로 이동
