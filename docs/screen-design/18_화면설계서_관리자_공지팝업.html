Description

Summary.

  • 공지사항 CRUD + 메인 페이지 팝업 설정 관리 화면
  • 공지 목록 테이블 + 작성/수정 폼 제공
  • 팝업 ON/OFF 토글로 메인 페이지 팝업 노출 제어
  • API_ADM_0060~0063 연동
1 관리자 사이드바 네비게이션
· 현재 메뉴(공지/팝업)는 파란색 활성 표시
2 페이지 타이틀
· "📢 공지사항 관리" 제목 + 서브텍스트
3 액션 버튼 2종
· "+ 공지 작성" — 하단 등록 폼 표시 (또는 별도 페이지)
· "⚙ 팝업 설정" — 팝업 공지 설정 모달 열기
4 공지사항 목록 테이블
API: GET /api/admin/notices (API_ADM_0060)
· 컬럼: 제목, 작성일, 조회수, 상태, 관리
· 상태 배지: 활성(녹색), 비활성(빨간)
· ✏️ 수정 클릭 → 등록 폼에 기존 데이터 pre-fill
· 🗑️ 삭제 클릭 → 확인 모달 후 삭제 처리
5 공지 작성/수정 폼
등록: POST /api/admin/notices (API_ADM_0061)
수정: PUT /api/admin/notices/{id} (API_ADM_0062)
· 필드: 제목, 내용(HTML 에디터), 첨부파일, 팝업 설정
· 내용은 리치 텍스트 에디터 적용 권장
· 첨부파일: PDF, 이미지 등 다중 업로드 가능
6 팝업 설정 토글
· ON 시 해당 공지가 메인 페이지 진입 시 팝업으로 표시
· 사용자 측 API: GET /api/notices/popup (API_NTC_0020)
· 복수 팝업 설정 시 최신 1개만 팝업 노출
· "오늘 하루 안보기"는 프론트 localStorage 관리
🎯 Event Description
E1공지 작성 (Create)
· 트리거: [+ 공지 작성] 버튼 클릭 → 폼 작성 → [등록]
· 동작: 제목/내용/첨부파일 전송
· API: POST /api/admin/notices
E2공지 수정 (Update)
· 트리거: ✏️ 버튼 클릭 → 폼에 기존 데이터 pre-fill → [등록]
· 동작: 공지 정보 수정
· API: PUT /api/admin/notices/{id}
E3공지 삭제 (Delete)
· 트리거: 🗑️ 버튼 클릭
· 동작: 확인 모달 → 공지 + 첨부파일 삭제
· API: DELETE /api/admin/notices/{id}
E4팝업 설정 토글 (Toggle Popup)
· 트리거: 팝업 ON/OFF 토글 클릭
· 동작: isPopup 필드 변경 → 메인 페이지 팝업 노출 여부 제어
· 복수 팝업 시 최신 1개만 노출
E5팝업 설정 모달 (Popup Config)
· 트리거: [⚙ 팝업 설정] 버튼 클릭
· 동작: 팝업 표시 공지 선택 모달 표시
E6사이드바 메뉴 이동 (Navigate Menu)
· 트리거: 좌측 사이드바 메뉴 항목 클릭
· 동작: 해당 관리자 메뉴 페이지로 이동

Check Point

· 관리자(ADMIN) 권한 검증 필수
· 삭제 시 확인 모달 필수 — 실수 방지
· 팝업 설정 ON/OFF 변경 시 즉시 반영
· 첨부파일은 파일 크기 제한 적용 (예: 10MB)
· 공지 삭제 시 관련 첨부파일도 함께 삭제 처리
· 삭제 API: DELETE /api/admin/notices/{id} (API_ADM_0063)
