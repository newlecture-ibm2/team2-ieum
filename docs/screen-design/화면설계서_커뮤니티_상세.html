Description

Summary.

  • 사용자들이 작성한 커뮤니티 게시글을 읽고 소통하는 상세페이지
  • 글의 전체 내용 및 첨부 이미지 확인과 댓글/좋아요 기능 제공
1 상단 네비게이션
· 좌측: 뒤로가기 버튼 (이전 커뮤니티 목록으로 이동)
· 중앙: "커뮤니티" 또는 해당 게시글 제목
· 우측: 메뉴(더보기) 점 3개 아이콘 (본인 글일 경우 수정/삭제 메뉴)
2 작성자 프로필 영역
· 작성자 프로필 이미지 (원형 마스크 적용)
· 닉네임 기재
· 작성 시간 (예: 방금 전, 2시간 전, 2026.03.29)
3 게시글 본문 (텍스트)
· 작성자가 입력한 제목과 텍스트 내용 표출
· 줄바꿈 및 스크롤 영역 적용
4 게시글 첨부 이미지 영역
· 본문에 첨부된 이미지가 있는 경우 리스트업
· 클릭 시 이미지 확대 보기(팝업) 기능 제공
5 인터랙션 액션 버튼
· 좋아요(공감) 버튼과 카운트 표시, 클릭 시 아이콘 색상 변경
· 댓글 수 및 조회수 요약 표시
6 댓글 목록 출력 영역
· 다른 사용자들이 남긴 댓글 리스트업
· 각 댓글의 작성자 프로필, 닉네임, 내용, 작성 시간 포함
7 댓글 입력창 (Sticky 요소)
· 화면 하단에 고정되어 있어 언제든 접근 가능
· 텍스트 입력 필드와 [등록] 버튼으로 구성
· 미입력 상태일 때는 [등록] 버튼 비활성화 (회색 차이)

Check Point

· 본인의 게시물일 경우 상단 메뉴(점 3개)를 통해 '수정', '삭제' 권한 부여
· 댓글 작성 즉시 목록 최하단(혹은 지정된 정렬순)에 동적으로 추가되어야 함
· 긴 텍스트의 경우 가독성을 해치지 않게 줄간격(Line-height) 유지 규칙 적용
