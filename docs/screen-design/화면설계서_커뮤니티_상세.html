Description

Summary.

  • 커뮤니티 게시글 내용 조회 및 댓글 소통을 위한 상세 페이지
  • 글의 속성(축제, 지역, 말머리)을 한 번에 파악할 수 있는 상단 메타 박스 지원
  • 게시글 작성자 본인에 한해 수정/삭제 컨트롤을 지원
1 작성자 정보 및 수정/삭제
· 게시글 작성일과 시간이 상단 배치
· 세션 정보와 작성자 ID 일치 시 우측에 [수정], [삭제] 액션 버튼 노출
2 게시물 메타 정보 태그
· 말머리, 축제명, 지역, 카테고리 4종의 조건 태그를 박스형태로 강조
· 클릭 시 해당 조건이 적용된 커뮤니티 리스트로 이동하거나 축제 상세로 이동
3 본문 내용 및 디자인
· 제목, 삽입된 이미지들, 줄바꿈이 반영된 긴 텍스트 렌더링
· 하단에는 하트 아이콘의 [공감] 토글 버튼 배치
4 댓글 / 대댓글 (계층형)
· 기본적으로 시간순으로 정렬된 댓글 노출
· 특정 댓글에 [답글 달기] 클릭 시 하위에 꺾쇠 아이콘과 함께 대댓글 렌더링
5 댓글 작성 폼
· 댓글 및 대댓글을 입력하는 인풋 필드 배치
· 로그인 유저만 활성화되며, 비로그인 시 진입 불가 또는 안내 문구 제공

Description

Summary.

  • 신규 커뮤니티 게시글을 작성하거나 기존 게시글을 수정하기 위한 공통 폼 화면
  • 글쓰기 시 필수 메타 정보(말머리, 축제 연동 등)를 구조적으로 입력받음
6 분류 및 관련 정보 매핑
· 말머리(Q&A, 리뷰 등)와 카테고리, 지역 등을 셀렉트 박스 형태로 지정
· "관련 축제" 선택 시 향후 축제 상세 페이지 내부 커뮤니티 탭에도 본 게시물이 연동되어 표출됨
7 제목 및 본문 입력
· 기본적인 텍스트 제목과 내용을 입력하는 에디터 폼 제공
· 수정 모드일 시, 기존에 작성했던 내용과 속성값들이 Value에 바인딩되어 나타남
8 이미지 업로드 & 하단 액션
· 박스 영역을 클릭하여 디바이스 내 이미지 파일을 멀티 업로드 지원
· [등록/저장] 버튼 서버 API 요청 시 Validation 통과 여부 검사
📡 Related API (상세/작성/댓글 공통)
Method Endpoint 설명 권한
GET /api/communities/{id} 커뮤니티 상세 및 메타 조회 비회원
POST /api/communities 게시글 신규 작성 저장 회원
PUT /api/communities/{id} 게시글 내용 및 속성 부분 수정 본인
POST /api/communities/{id}/comments 댓글 및 대댓글 등록 회원
DEL /api/communities/{id} 게시물 및 등록된 댓글 일괄 삭제 처리 본인
