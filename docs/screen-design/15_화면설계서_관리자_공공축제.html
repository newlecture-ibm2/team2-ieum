Description

Summary.

  • 공공 API(data.go.kr)에서 수집된 전국 축제 데이터를 관리하는 화면
  • 수동 갱신 버튼으로 공공 데이터 동기화 가능
  • 축제 상태(진행중/진행전/종료) 요약 카드 4종 제공
  • 축제 목록 테이블에서 노출/숨김, 수정, 삭제 관리
  • 좌측 사이드바로 관리자 메뉴 간 이동
1 관리자 사이드바 네비게이션
· 좌측 고정 사이드바, 다크(#1e293b) 배경
· 관리 메뉴: 대시보드, 공공축제 리스트, 자체기획 축제, 신고, 공지/팝업, 문의
· 현재 메뉴(공공축제 리스트)는 파란색(#6c5ce7) 활성 표시
2 페이지 타이틀
· "🌐 공공 축제 리스트" 제목 + 서브텍스트
· 관리자(ADMIN) 권한 로그인 사용자만 접근 가능
3 공공 API 데이터 갱신 영역
API: POST /api/admin/festivals/sync (API_ADM_0031)
· "수동 갱신" 버튼 클릭 → data.go.kr API 호출 → 축제 데이터 동기화
· 최근 갱신 일시 표시
· 동기화 완료 시 syncCount 결과 알림
4 상태 요약 카드 (4종)
API: GET /api/admin/festivals (API_ADM_0030) 응답 집계
· 전체 축제 — 전체 갯수
· 진행중 — 현재 운영 중인 축제 수
· 진행예정 — 시작 전 축제 수
· 종료 — 종료된 축제 수
· 각 카드는 배경 색상으로 구분
5 축제 목록 테이블
API: GET /api/admin/festivals (API_ADM_0030)
· 컬럼: 축제명, 지역, 날짜, 카테고리, 상태, 관리
· 축제명 클릭 → 축제 상세 페이지 이동
· 상태 배지: 진행중(녹색), 진행전(파란), 종료(회색)
· 페이지네이션 지원 (page, size 파라미터)
6 관리 액션 버튼
API: PATCH /api/admin/festivals/{id}/visibility (API_ADM_0032)
· ✏️ 수정 — 축제 노출/숨김 설정 변경
· 🗑️ 삭제 — 축제 숨김 처리 (확인 모달 후)
· isVisible 토글로 사용자 화면 노출 여부 제어

Check Point

· 관리자(ADMIN) 권한 검증 필수 — 비관리자 접근 시 403 Forbidden
· 수동 갱신 중 중복 요청 방지 (FEST_003: 이미 동기화 진행 중)
· 수동 갱신 버튼 클릭 시 로딩 스피너 표시
· 축제 삭제는 실제 삭제가 아닌 isVisible=false 처리 (소프트 삭제)
· 페이지네이션 기본값: page=1, size=10
· 공공 API 호출 실패 시 FEST_002 에러 표시
