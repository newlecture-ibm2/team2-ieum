Description

Summary.

  • 관리자 전용 대시보드로, 플랫폼 전반의 핵심 지표를 한 화면에서 확인
  • 총 사용자, 리뷰, 진행 축제, 채팅 활동 등 4개 KPI 요약 카드 제공
  • 지역별/시간대별/카테고리별 3종 그래프로 데이터 시각화
  • 좌측 사이드바로 관리자 메뉴 간 이동
  • API_ADM_0010 (통계 요약) + API_ADM_0020~0022 (그래프 데이터) 연동
1 관리자 사이드바 네비게이션
· 좌측 고정 사이드바, 다크(#1e293b) 배경
· 관리 메뉴: 대시보드, 공공축제 리스트, 축제 등록, 신고, 공지/팝업, 문의
· 현재 메뉴(대시보드)는 파란색(#6c5ce7) 활성 표시
2 페이지 타이틀 + 서브텍스트
· "관리자 대시보드" 제목과 안내 문구 표시
· 관리자 권한(ADMIN)으로 로그인한 사용자만 접근 가능
3 KPI 요약 카드 (4종)
API: GET /api/admin/dashboard (API_ADM_0010)
· 총 사용자 — totalUsers.count + growth%
· 총 리뷰 — newReviews.count + growth%
· 진행 축제 — activeFest.count + growth
· 채팅 활동 — 채팅 메시지 수 + growth%
각 카드는 그라데이션 배경 + 전월 대비 증감률 표시
4 지역별 축제 분포 (막대 그래프)
API: GET /api/admin/dashboard/regions (API_ADM_0021)
· 세로 막대 차트로 지역별 축제 갯수 비교 시각화
· X축: 지역명 (서울, 부산, 강릉, 전주, 평창, 진해, 광주, 기타)
· Y축: 축제 수 (0~60)
· 그라데이션 보라색 바 스타일 적용
5 사용자 유입 및 활동 추이 (라인 차트)
API: GET /api/admin/dashboard/traffic (API_ADM_0020)
· 월별 추이를 3개 라인으로 다중 표시
· ■ 사용자 (파란 실선) — 가입 사용자 수
· ■ 리뷰 (녹색 점선) — 리뷰 작성 수
· ■ 채팅 (오렌지 실선) — 채팅 메시지 수
· X축: 기간 (1월~4월), Y축: 0~26,000
· period 파라미터로 day/week/month 단위 전환 가능
6 축제 카테고리별 분포 (파이 차트)
API: GET /api/admin/dashboard/categories (API_ADM_0022)
· 도넛/파이 차트로 카테고리 비율 시각화
· 자연/꽃 35% | 문화/예술 28% | 음식/먹거리 15% | 전통/역사 12% | 기타 10%
· 우측에 색상 범례 + 비율(%) 표시
🎯 Event Description
E1사이드바 메뉴 이동 (Navigate Menu)
· 트리거: 좌측 사이드바 메뉴 항목 클릭
· 동작: 해당 관리자 메뉴 페이지로 이동
E2대시보드 데이터 로드 (Data Load)
· 트리거: 페이지 마운트
· 동작: 4개 API 병렬 호출 (KPI + 그래프 3종)
· 로딩 중 스켈레톤 UI 적용
E3트래픽 기간 전환 (Period Toggle)
· 트리거: period 파라미터 변경 (day/week/month)
· 동작: 라인 차트 데이터 갱신
· API: GET /api/admin/dashboard/traffic?period={period}

Check Point

· 관리자(ADMIN) 권한 검증 필수 — 비관리자 접근 시 403 Forbidden 처리
· KPI 카드의 전월 대비 증감률은 서버에서 계산된 growth 필드 사용
· 그래프는 Chart.js 또는 Recharts 라이브러리 활용 권장
· 트래픽 그래프는 period(day/week/month) 파라미터로 기간 단위 전환 가능
· 대시보드 데이터는 페이지 진입 시 4개 API 병렬 호출로 로딩 최적화
· 데이터 로딩 중 스켈레톤 UI 적용
