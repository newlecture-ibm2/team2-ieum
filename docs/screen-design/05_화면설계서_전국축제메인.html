Summary.

  • 전국의 축제를 카드형 그리드로 조회하는 메인 화면
  • 탭(전체/진행중/진행예정/지도)으로 상태별 필터링
  • 검색 + 지역/카테고리 필터로 원하는 축제 빠른 탐색
  • 공공 API + 자체 등록 축제 데이터 통합 제공
1 GNB 네비게이션 (공통 헤더)
현재 "전국축제" 탭 활성 표시
🔔 알림 아이콘 + 👤 마이페이지 아이콘
2 히어로 배너 + 탭 필터
· 퍼플 그라데이션 히어로 영역
· Pill 스타일 탭: 전체 / 진행중 / 진행예정 / 🗺️ 지도
3 검색/필터 영역 (공통 Type A)
검색바 + 필터 버튼 + 퍼플 검색 버튼
우측 정렬 드롭다운 (최신순/인기순/별점순)
공통 스타일: 라운드 10px 카드, #f8f9fa 입력 배경
4 필터 버튼

적용된 필터를 퍼플 태그로 표시
✕ 버튼으로 개별 해제 가능

3열 카드 레이아웃
카드 구성: 대표이미지 + 진행상태 배지 + 찜♡ + 축제명 + 기간 + ★ 별점(리뷰 수)
7 찜하기 아이콘 (♡/❤️)
카드 우상단 하트 아이콘

🎯 Event Description
E1 탭 필터 전환 (Switch Tab)
· 트리거: 전체/진행중/진행예정/지도 탭 클릭
· 동작: URL의 status 쿼리 파라미터 변경 + API 재호출
· 지도 탭 클릭 시: 지도 뷰 화면(UI-F-002)으로 전환
· API: GET /api/festivals?status={status}
E2 검색 실행 (Execute Search)
· 트리거: 검색 버튼 클릭 또는 Enter 입력
· 동작: 키워드 기반 축제 검색 + 결과 카드 갱신
· API: GET /api/festivals?keyword={keyword}
E3 필터 모달 열기/적용 (Open/Apply Filter)
· 트리거: [필터] 버튼 클릭
· 동작: 지역별/카테고리별 필터 모달 표시
· 적용 시: 하단에 필터 태그 표시 + 카드 목록 갱신
E4 필터 태그 제거 (Remove Filter Tag)
· 트리거: 태그 ✕ 클릭
· 동작: 해당 필터 해제 + URL 파라미터 업데이트 + 목록 즉시 갱신
E5 카드 클릭 (Navigate to Detail)
· 트리거: 축제 카드 클릭
· 동작: /festivals/{festivalId} 상세 페이지로 라우팅 이동
E6 찜하기 토글 (Toggle Scrap)
· 트리거: ♡ 아이콘 클릭
· 비로그인: 로그인 유도 팝업 표시
· 로그인 시: 찜/찜해제 토글
· API: POST /api/festivals/{id}/scrap
E7 정렬 변경 (Change Sort)
· 트리거: 정렬 드롭다운 선택 변경
· 동작: 최신순/인기순/별점순으로 카드 재정렬
E8 페이지 전환 (Pagination)
· 트리거: 페이지 번호 또는 ◀▶ 클릭
· 동작: 서버사이드 페이징 (page, size 파라미터) + 카드 목록 갱신

Check Point

· API: GET /api/festivals?status=®ion=&page=1&size=9
· 카드 클릭 시 /festivals/{festivalId} 상세 페이지 이동
· 탭 전환 시 status 쿼리 파라미터 변경, API 재호출
· 지도 탭 클릭 시 지도 뷰 화면으로 전환
· 찜하기는 로그인 필요 (POST /api/festivals/{id}/scrap)
· 비회원도 목록 조회 가능
