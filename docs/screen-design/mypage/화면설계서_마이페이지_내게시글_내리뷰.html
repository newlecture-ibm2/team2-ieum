Description

Summary.

  • 사용자가 직접 작성한 커뮤니티 게시글 및 축제 리뷰를 모아보는 화면
  • 리스트 형태로 제공되며, 각 항목에서 바로 글 수정/삭제가 가능
  • 게시글/리뷰 탭 전환을 통해 필터링 가능
1 게시글 / 리뷰 분류 탭
· 내 게시글 (12) — 현재 활성 탭, 파란색 하단 밑줄로 표시
· 내 리뷰 (4) — 비활성 상태, 클릭 시 리뷰 목록으로 전환
탭 전환 시 하단 리스트가 해당 콘텐츠로 동적 교체
2 게시글 리스트 항목
각 글 카드 구성:
· 게시글 제목 (굵은 텍스트, 카테고리 태그 포함)
· 작성 일자 (우측 회색 텍스트)
· 본문 미리보기 (2~3줄 스니펫)
제목 클릭 시 해당 게시글 원문 페이지로 이동
3 [수정] 버튼
각 항목 우측 하단에 위치
클릭 시 해당 글의 수정 폼(모달 또는 페이지)이 열리며 기존 데이터 바인딩
4 [삭제] 버튼
각 항목 우측 하단에 위치 (빨간색 강조)
클릭 시 삭제 확인 팝업 호출
확인 시 해당 글 삭제 및 연동된 댓글·대댓글 일괄 블라인드 처리
5 리뷰 탭 전환 시 추가 요소
리뷰 탭 활성 시 동일한 리스트 구조 내에 추가 표시:
· ⭐ 별점 정보 (5점 만점)
· 리뷰가 달린 축제명 표시

Check Point

· 글 삭제 시 연결된 답글 및 하위 댓글들이 모두 화면에서 블라인드(숨김) 처리
· 답글 작성자의 마이페이지에서도 해당 답글이 노출되지 않도록 데이터 블라인드
· 리스트가 길어질 경우 무한 스크롤 또는 페이지네이션 적용
· 리뷰 탭 전환 시 동일한 UI 구조 내에서 별점 컴포넌트만 추가 표시
