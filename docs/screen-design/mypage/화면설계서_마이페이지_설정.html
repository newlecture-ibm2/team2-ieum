Description

Summary.

  • 회원 계정 관리를 위한 통합 설정 대시보드 화면
  • 프로필 편집(이미지 / 닉네임)과 알림 수신 On/Off를 한 페이지에서 관리
  • 회원 탈퇴 기능도 해당 화면에서 진입 가능
1 프로필 이미지 변경 영역
· 원형 프로필 썸네일 + [📷 사진 업데이트] 버튼
· 지원 포맷: JPG, PNG (최대 5MB)
2 닉네임 변경 + 중복확인
· 입력 필드에 현재 닉네임이 기본값으로 채워짐
· [중복확인] 버튼 배치
· 유효성 검사 (길이 제한, 특수문자 제한 등) 적용
3 이메일 주소 표시
· 읽기 전용으로 현재 등록된 이메일 계정 노출
· 본 화면에서 이메일 변경은 불가
4 [프로필 저장 적용] 버튼
파란색 강조 버튼으로 배치
5 [회원 탈퇴 진행] 링크
· 우측 하단에 빨간색 텍스트 링크로 배치
6 알림 토글 스위치
· 마케팅 정보 수신 — 이벤트, 프로모션 안내 등 광고성 정보 On/Off
· 내 콘텐츠 반응 알림 — 내 글/리뷰에 답글이 달릴 경우 푸시 On/Off
· 고객센터 처리 상태 알림 — 1:1 문의 답변 등록 시 푸시 On/Off
각 토글은 ON(파란) / OFF(회색) 상태로 시각적 구분
🎯 Event Description
E1 [📷 사진 업데이트] 클릭 (Upload Profile Image)
· 트리거: 사진 업데이트 버튼 클릭
· 동작: OS 파일 업로드 다이얼로그 실행 → 이미지 선택
· 결과: 선택된 이미지 미리보기 표시 (저장 전 프리뷰)
· 제한: JPG, PNG / 최대 5MB
E2 [중복확인] 버튼 클릭 (Check Nickname Availability)
· 트리거: 닉네임 입력 후 [중복확인] 클릭
· 동작: 서버에 닉네임 사용 가능 여부 비동기 조회
· 성공 시: "사용 가능한 닉네임입니다" 안내 + 저장 버튼 활성화
· 실패 시: "이미 사용 중인 닉네임입니다" 경고
E3 [프로필 저장 적용] 클릭 (Save Profile)
· 트리거: 프로필 저장 버튼 클릭
· 전제: 닉네임 중복확인 완료 상태에서만 활성
· 동작: 닉네임 + 프로필 이미지 변경사항을 서버에 저장
· API: PATCH /api/users/me/profile
· 완료 시: "프로필이 저장되었습니다" 토스트 메시지
E4 [회원 탈퇴 진행] 클릭 (Withdraw)
· 트리거: 회원 탈퇴 링크 클릭
· 동작: 탈퇴 경고 모달(정책 안내 + 동의 체크박스) 표시
· 동의 후 [탈퇴] 클릭 시: 계정 비활성화 처리 + 로그아웃
· 취소 시: 모달 닫힘
E5 알림 토글 전환 (Toggle Notification)
· 트리거: 각 알림 항목의 토글 스위치 클릭
· 동작: ON↔OFF 상태 즉시 전환 + 서버에 즉시 반영 (별도 저장 버튼 없음)
· API: PATCH /api/users/me/settings/notifications
· 시각적 피드백: ON(퍼플) / OFF(회색) 색상 전환
E6 사이드바 메뉴 클릭 (Menu Navigation)
· 트리거: 좌측 사이드바 메뉴 항목 클릭
· 동작: 클릭된 메뉴에 active 스타일 적용, 해당 서브 페이지로 이동

Check Point

· 닉네임 변경 시 반드시 [중복확인] 단계를 거친 후에만 저장 버튼 활성화
· 회원 탈퇴 시 정책 안내 동의 프로세스(팝업) 반드시 삽입
· 알림 토글 상태 변경 시 서버에 즉시 반영 (별도 저장 버튼 없이 토글 즉시 적용)
· 프로필 이미지 업로드 후 미리보기 제공
· 탈퇴 모달에서 동의 체크 없이 탈퇴 버튼 비활성
