Description

Summary.

  • 회원 전용 마이페이지의 기본 화면으로, 즐겨찾기(찜) 목록을 카드형으로 조회
  • 좌측 사이드바를 통해 게시글, 리뷰, 댓글, 문의, 알림 설정 등 전체 탭 전환 가능
  • 프로필 정보 확인 및 프로필·알림 설정 페이지 진입 가능
1 상단 네비게이션 바
전국축제 | 지난축제 | 달력 | 커뮤니티 | 공지
우측에 검색, 알림, 사용자 닉네임 표시
모든 마이페이지 탭에서 동일하게 유지
2 사용자 프로필 영역
· 프로필 이미지 (원형 썸네일)
· 닉네임 (굵은 텍스트)
· 이메일 주소 (회색 서브텍스트)
· [프로필 · 알림 설정] 버튼 → 클릭 시 설정 탭으로 이동
3 좌측 탭 메뉴 (사이드바)
· ❤️ 즐겨찾기 목록 (현재 활성 - 파란색 하이라이트)
· 📝 내 게시글 목록
· ⭐ 내 리뷰 목록
· 💬 내 댓글 목록
· ❓ 내 문의 보기
· ⚙️ 내 알림 설정
각 항목 클릭 시 우측 콘텐츠 영역이 해당 탭으로 전환
4 즐겨찾기 카운트 표시
현재 즐겨찾기에 등록된 축제의 총 갯수를 타이틀 옆에 표시
예: "즐겨찾기 목록 (총 12개)"
5 즐겨찾기 축제 카드 리스트
2열 그리드 레이아웃으로 찜한 축제 카드 배치
각 카드 구성:
· 축제 대표 이미지 (상단 썸네일)
· 축제명 (굵은 텍스트)
· 위치 (📍 아이콘 + 지역명) + 기간 (📅 아이콘 + 날짜)
카드 클릭 시 해당 축제 상세 페이지로 이동
6 [❤️ 해제] 버튼
각 카드 우측 하단에 위치
클릭 시 즐겨찾기 목록에서 즉시 제거
제거 후 하단에 "즐겨찾기가 해제되었습니다" 토스트 메시지 노출

Check Point

· 비로그인 상태일 경우 로그인 페이지로 리다이렉트 (회원 전용 페이지)
· 즐겨찾기 해제 시 카운트도 동적으로 갱신
· 즐겨찾기 목록이 많을 경우 페이지네이션 또는 무한 스크롤 적용
· 좌측 메뉴 구조는 모든 마이페이지 탭에서 100% 동일하게 유지
