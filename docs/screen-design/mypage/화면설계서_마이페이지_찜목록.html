Description

Summary.

  • 회원 전용 마이페이지의 기본 화면으로, 즐겨찾기(찜) 목록을 카드형으로 조회
  • 좌측 사이드바를 통해 게시글, 리뷰, 댓글, 문의, 알림 설정 등 전체 탭 전환 가능
  • 프로필 정보 확인 및 프로필·알림 설정 페이지 진입 가능
1 상단 네비게이션 바
전국축제 | 지난축제 | 달력 | 커뮤니티 | 공지
우측에 검색, 알림, 사용자 닉네임 표시
모든 마이페이지 탭에서 동일하게 유지
2 사용자 프로필 영역
· 프로필 이미지 (원형 썸네일)
· 닉네임 (굵은 텍스트)
· 이메일 주소 (회색 서브텍스트)
· [프로필 · 알림 설정] 버튼 배치
3 좌측 탭 메뉴 (사이드바)
· ❤️ 즐겨찾기 목록 (현재 활성 - 퍼플 하이라이트)
· 📝 내 게시글 목록
· ⭐ 내 리뷰 목록
· 💬 내 댓글 목록
· ❓ 내 문의 보기
· ⚙️ 내 알림 설정
4 즐겨찾기 카운트 표시
현재 즐겨찾기에 등록된 축제의 총 갯수를 타이틀 옆에 표시
예: "즐겨찾기 목록 (총 12개)"
5 즐겨찾기 축제 카드 리스트
2열 그리드 레이아웃으로 찜한 축제 카드 배치
각 카드 구성:
· 축제 대표 이미지 (상단 썸네일)
· 축제명 (굵은 텍스트)
· 위치 (📍 아이콘 + 지역명) + 기간 (📅 아이콘 + 날짜)
6 [❤️ 해제] 버튼
각 카드 우측 하단에 위치
🎯 Event Description
E1 축제 카드 클릭 (Navigate to Festival Detail)
· 트리거: 즐겨찾기 축제 카드 영역 클릭
· 동작: 해당 축제의 상세 페이지로 라우팅 이동
· 결과: /festivals/{festivalId} 페이지로 이동
E2 [❤️ 해제] 버튼 클릭 (Remove Scrap)
· 트리거: 카드 우측 하단 [❤️ 해제] 버튼 클릭
· 동작: 즐겨찾기 목록에서 즉시 제거 + 카운트 동적 갱신
· 결과: "즐겨찾기가 해제되었습니다" 토스트 메시지 노출
· API: POST /api/festivals/{festivalId}/scrap (토글)
E3 [프로필 · 알림 설정] 클릭 (Navigate to Settings)
· 트리거: 프로필 영역 하단 [프로필 · 알림 설정] 버튼 클릭
· 동작: 설정 탭(UI-M-005)으로 라우팅 이동
E4 사이드바 메뉴 클릭 (Menu Navigation)
· 트리거: 좌측 사이드바 메뉴 항목 클릭
· 동작: 클릭된 메뉴에 active 스타일 적용, 해당 서브 페이지로 이동
E5 카드 Hover 효과
· 트리거: 축제 카드 영역에 마우스 진입
· 동작: 카드 그림자 강조 + 미세 scale-up 효과
· 결과: 클릭 가능한 카드임을 시각적으로 전달
E6 무한 스크롤 / 페이지네이션 (Load More)
· 트리거: 카드 리스트 하단 도달
· 동작: 다음 페이지 데이터 비동기 로드
· API: GET /api/festivals/scraps?page={n}&size=10
E7 빈 상태 (Empty State)
· 트리거: 즐겨찾기 0건
· 동작: 빈 상태 일러스트 + "아직 즐겨찾기한 축제가 없어요." + [축제 보러가기] CTA 버튼

Check Point

· 비로그인 상태일 경우 로그인 페이지로 리다이렉트 (회원 전용 페이지)
· 즐겨찾기 해제 시 카운트도 동적으로 갱신
· 즐겨찾기 목록이 많을 경우 페이지네이션 또는 무한 스크롤 적용
· 좌측 메뉴 구조는 모든 마이페이지 탭에서 100% 동일하게 유지
· 해제 후 되돌리기(Undo) 기능 고려
