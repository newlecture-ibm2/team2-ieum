Description

Summary.

  • 사용자가 작성한 댓글 및 답글(대댓글)을 계층 구조로 모아보는 화면
  • 댓글이 달린 원본 게시물 단위로 그루핑하여 시인성 확보
  • 본인 댓글에 대한 수정/삭제 및 하위 답글 블라인드 정책 적용
1 댓글 카운트 표시
현재 내가 작성한 댓글의 총 갯수를 타이틀 옆에 표시
예: "내 댓글 목록 (총 4개)"
2 원문 게시글 그룹 블록
댓글이 달린 원본 게시물(또는 축제명)을 파란색 배경의 타이틀 블록으로 표시
블록 클릭 시 원본 게시글 페이지로 링크 이동 가능
3 내 댓글 (본인 작성)
· 닉네임 옆 파란색 [작성자] 배지로 본인 댓글 강조 표시
· 댓글 본문 텍스트 + 작성 일시
· 우측에 [수정] / [삭제] 버튼 노출
4 타인의 답글 (대댓글)
· 왼쪽 세로선(인덴트)으로 계층 구분 표시
· 회색 [답글] 배지 + 닉네임 + 작성 일시
· 타인 답글에는 수정/삭제 버튼 비활성
5 나의 대댓글 (답글에 대한 답글)
· 추가 인덴트(2단 들여쓰기)로 2차 계층 표현
· 파란색 [작성자] 배지 + [수정] / [삭제] 버튼 활성
6 [수정] / [삭제] 액션 버튼
· [수정]: 인라인 수정 모드 또는 수정 폼 팝업 전환
· [삭제]: 삭제 확인 팝업 호출 후 처리
· 삭제 시 해당 댓글의 하위 답글(대댓글)도 일괄 블라인드 처리

Check Point

· [중요 정책] 본인의 상위 댓글을 삭제할 경우 하위 답글(대댓글) 모두 함께 블라인드 처리
· 삭제된 댓글의 답글 작성자의 마이페이지에서도 해당 데이터는 더 이상 노출되지 않음
· 답글에 대한 답글도 포함하여 모아보기 제공 (계층 무제한은 아님, 최대 2단계까지)
· 댓글 목록이 많을 경우 페이지네이션 적용
