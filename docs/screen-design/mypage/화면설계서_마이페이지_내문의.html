Description

Summary.

  • 1:1 고객 문의 내역과 답변 상태를 한 번에 조회하는 CS 센터 화면
  • 아코디언 UI를 활용하여 질문과 답변을 빠르게 열람 가능
  • 신규 문의 작성 및 답변 대기/완료 상태 관리 제공
1 [+ 1:1 문의 작성] 버튼
우측 상단에 파란색 강조 버튼으로 배치
클릭 시 1:1 문의 작성 폼 페이지 또는 모달로 이동
2 문의 목록 아코디언 리스트
각 행 구성:
· 문의 제목 (굵은 텍스트)
· 등록 일자 (우측 회색 텍스트)
· ▼ / ▲ 아이콘으로 접기/펼치기 상태 표시
행 클릭 시 해당 문의의 Q&A 상세 내용이 슬라이드다운으로 전개
3 문의 처리 상태 배지
· 답변대기 (회색 배경 배지) — 아직 관리자 답변이 등록되지 않은 상태
· 답변완료 (초록색 배경 배지) — 관리자가 답변을 완료한 상태
4 아코디언 펼침 영역 (Q&A 상세)
펼쳐진 상태의 콘텐츠 구성:
· Q (검정색 원형 아이콘) — 나의 질문 내용 표시
· A (파란색 원형 아이콘) — 운영팀 답변 내용 표시
질문과 답변 영역 사이 점선 구분선으로 시각적 분리
5 답변 대기 상태 문의 액션
답변 대기(Pending) 상태의 문의 항목에 한해:
· 펼침 시 문의 내용 수정 가능
· 문의 삭제 가능 (삭제 확인 팝업 호출)
답변 완료 상태의 문의는 수정 불가

Check Point

· 답변완료(Answered) 상태의 문의는 수정/삭제 불가 제한 적용
· 답변대기(Pending) 상태의 문의만 수정 및 삭제 가능
· 문의 목록이 많을 경우 페이지네이션 적용
· 신규 문의 작성 시 필수 입력 항목 유효성 검사 적용
