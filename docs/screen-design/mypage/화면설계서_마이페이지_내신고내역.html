Description

Summary.

사용자가 타 유저나 게시글에 대해 제출한 신고 내역을 확인하는 화면입니다. 관리자의 처리 결과 및 답변을 확인할 수 있습니다.

1신고 내역 카드: 신고된 사안별로 요약 정보를 제공하는 카드형 리스트
2처리 상태 배지: 접수대기(황색), 처리완료(녹색), 반려(적색)로 직관적 구분
3상세 보기 (열림 상태): 특정 신고 건을 클릭할 경우 상세 내용과 답변이 확장됨
4신고 상세 본문: 사용자가 신고 시 작성한 구체적인 서술 내용
5관리자 피드백: 신고 처리 결과에 대한 담당자의 최종 공식 답변 영역
6사이드바 연동: 내 문의, 즐겨찾기 등 마이페이지 공통 네비게이션 제공
7[원글 보기] 버튼: 신고 대상이 된 실제 게시글/댓글 상세 페이지로 즉시 이동
🎯 Event Description
E1신고 항목 클릭: 해당 카드 영역 확장 및 상세 내역(신고 내용/관리자 답변) 노출
E2[원글 보기] 클릭: 신고된 대상의 상세 페이지로 새 창(또는 현재 창) 이동 (/community/posts/{id} 등)
E3무한 스크롤: 내역이 많을 경우 하단 스크롤 시 추가 데이터 로드 (GET /api/users/me/reports)
