Description

Summary.

  • 사용자가 등록한 1:1 문의를 확인하고 답변하는 화면
  • 문의 목록 테이블 + 상세/답변 영역 제공
  • 대기중/답변완료 상태 관리
  • API_ADM_0070~0072 연동
1 관리자 사이드바 네비게이션
· 현재 메뉴(문의 관리)는 파란색 활성 표시
2 페이지 타이틀
· "💬 사용자 문의 관리" 제목 + 서브텍스트
3 문의 목록 테이블
API: GET /api/admin/inquiries (API_ADM_0070)
· 컬럼: #, 제목, 작성자, 작성일, 상태, 관리
· 상태 배지: 대기중(노란), 답변완료(녹색)
· 대기중 → [답변] 버튼, 답변완료 → 📋 아이콘(상세 보기)
· 행 hover 시 배경색 변경 (클릭 가이드)
4 관리 액션
· [답변] — 하단 상세+답변 영역 펼침
· 📋 — 답변 완료된 문의의 상세/답변 내용 확인
5 문의 상세 영역
API: GET /api/admin/inquiries/{id} (API_ADM_0071)
· 작성자 정보, 작성일, 제목, 내용 표시
· 목록에서 [답변] 또는 📋 클릭 시 하단에 표시
6 답변 작성 + 등록
API: POST /api/admin/inquiries/{id}/answer (API_ADM_0072)
· 답변 텍스트 입력 영역
· "답변 등록" 클릭 → answer 필드 전송
· 등록 성공 시 상태가 "답변완료"로 자동 변경
· sentAt 타임스탬프 서버에서 자동 생성
🎯 Event Description
E1 답변 버튼 클릭 (Open Reply)
· 트리거: [답변] 버튼 클릭
· 동작: 해당 문의 상세 + 답변 작성 영역 펼침
· API: GET /api/admin/inquiries/{id}
E2 답변 등록 (Submit Reply)
· 트리거: 답변 작성 후 [답변 등록] 버튼 클릭
· 동작: 유효성 검사 → 답변 전송 → 상태 "답변완료" 변경
· API: POST /api/admin/inquiries/{id}/answer
E3 답변 상세 보기 (View Detail)
· 트리거: 📋 아이콘 클릭 (답변완료 문의)
· 동작: 문의 상세 + 등록된 답변 내용 표시
E4 행 호버 인터랙션 (Row Hover)
· 트리거: 테이블 행 마우스 호버
· 동작: 배경색 #f8fafc 변경 (클릭 유도)
E5 사이드바 메뉴 이동 (Navigate Menu)
· 트리거: 좌측 사이드바 메뉴 항목 클릭
· 동작: 해당 관리자 메뉴 페이지로 이동

Check Point

· 관리자(ADMIN) 권한 검증 필수
· 답변 등록 후 해당 사용자에게 알림 발송 고려 (FCM 연동)
· 이미 답변 완료된 문의에 재답변 불가 (또는 수정 기능 검토)
· 답변 내용은 빈 문자열 불가 — 프론트 유효성 검사
· 사용자 측에서는 GET /api/users/me/inquiries/{id}로 답변 확인
· 페이지네이션 지원 (page, size)
