Description

Summary.

  • 등록된 회원 정보를 조회하고 상태·역할을 관리하는 화면
  • 회원 목록 테이블 + 상세 모달 제공
  • 정상/정지/탈퇴 상태 관리 및 역할 변경
  • 신고 4건 이상 회원 7일 정지 기능
  • API_ADM_0080~0084 연동
1 관리자 사이드바 네비게이션
· 현재 메뉴(회원 관리)는 그라데이션 활성 표시
2 페이지 타이틀 + 정지 카운트 뱃지
· "👥 회원 관리" 제목 + 서브텍스트
· 우측 정지 중 인원 알림 뱃지
3 KPI 통계 카드 (4종)
API: GET /api/admin/members (API_ADM_0080)
· 전체 / 정상 회원 / 정지 회원 / 탈퇴 대기
· 클릭 시 해당 상태로 필터 적용
4 필터 바
· 상태: 전체/정상/정지/탈퇴
· 역할: 전체/일반회원/관리자
· 검색: 전체/이름/닉네임/아이디 + 키워드
5 회원 목록 테이블
· 컬럼: No, 닉네임, 아이디, 역할, 가입일, 신고, 상태, 관리
· 신고 4건↑: 빨간 폰트로 강조
· 행 클릭 또는 [상세보기] → 모달 오픈
6 상세보기 버튼
· 클릭 시 회원 상세 모달(⑦) 오픈
· 행 전체 클릭으로도 동일 동작
7 회원 상세 모달
API: GET /api/admin/members/{userId} (API_ADM_0081)
· 프로필 카드: 프로필 이미지, 닉네임, 이메일, 역할/상태 배지
· 기본 정보 그리드: 회원번호, 이름, 가입일, 신고횟수
· 정지 중인 회원: 정지 해제 예정일 및 D-N 표시
8 신고 횟수 강조
· 4건 이상: 빨간 배경 + "정지 가능" 뱃지 (펄스 애니메이션)
· 2~3건: 노란 배경 경고
· 1건 이하: 일반 표시
9 관리 액션 버튼
· 🚫 7일 정지: 신고 4건↑ 회원만 활성화
  API: PATCH /members/{id}/status (API_ADM_0082)
· ✅ 정지 해제: 정지 회원에만 표시
· 👑 관리자 부여 / 👤 일반 회원으로: 역할 토글
  API: PATCH /members/{id}/role (API_ADM_0084)
· 🗑️ 강제 탈퇴: 소프트 삭제 처리
  API: DELETE /members/{id} (API_ADM_0083)
· 모든 액션은 인라인 확인 모달로 2차 확인
🎯 Event Description
E1 KPI 카드 클릭 (Filter by Status)
· 트리거: 상단 KPI 카드 클릭
· 동작: 해당 상태로 목록 필터 적용 (토글)
E2 상세보기 클릭 (Open Modal)
· 트리거: 행 클릭 또는 [상세보기] 버튼 클릭
· 동작: 회원 상세 모달 오픈
· API: GET /api/admin/members/{userId}
E3 7일 정지 (Suspend Member)
· 트리거: [🚫 7일 정지] 버튼 클릭
· 조건: 신고 4건 이상
· 동작: 인라인 확인 → 상태 변경
· API: PATCH /api/admin/members/{id}/status
E4 역할 변경 (Change Role)
· 트리거: [👑 관리자 부여] 또는 [👤 일반 회원으로] 클릭
· 동작: 인라인 확인 → 역할 변경
· API: PATCH /api/admin/members/{id}/role
E5 강제 탈퇴 (Delete Member)
· 트리거: [🗑️ 강제 탈퇴] 버튼 클릭
· 동작: 인라인 확인 → 소프트 삭제 처리
· API: DELETE /api/admin/members/{id}

Check Point

· 관리자(ADMIN) 권한 검증 필수
· 신고 4건 미만 회원은 정지 버튼 비활성화 (UI에서 제어)
· 모든 상태 변경 액션은 인라인 확인 모달로 2차 확인
· 정지 해제 예정일(D-Day) 실시간 표시
· 강제 탈퇴는 소프트 삭제 — 물리 삭제 아님
· 역할 변경 시 현재 로그인한 관리자 본인 제외 검토
· 페이지네이션 지원 (page, size)
