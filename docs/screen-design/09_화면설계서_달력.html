Description

Summary.

  • 월별 캘린더로 축제 일정을 한눈에 조회하는 페이지
  • 날짜별 축제 개수 표시, 날짜 클릭 시 해당 행이 밀리면서 축제 카드 리스트 노출
  • 축제 카드가 많으면 가로 스크롤로 탐색 가능
  • 비회원도 조회 가능
1 GNB 네비게이션 (공통 헤더)
현재 "달력" 탭 활성 표시
🔔 알림 아이콘 (로그인 시 알림 드롭다운 연동)
2 페이지 타이틀
"📅 축제 달력" — 페이지 제목 표시
3 월 이동 네비게이션
"2026년 3월" 연월 표시 + ◀ ▶ 버튼
클릭 시 이전/다음 월로 이동, API 재호출
4 캘린더 요일 헤더
일~토 요일 표시 (퍼플 그라데이션 배경)
일요일: 빨간색, 토요일: 파란색
5 날짜 셀 (축제 개수)
각 날짜에 진행 중인 축제 개수 표시
오늘 날짜: 퍼플 원형 배경으로 하이라이트
클릭 시 해당 행 아래에 축제 리스트 확장
6 축제 개수 카운트
start_date ~ end_date 범위에 포함되면 카운트
0개인 날짜는 카운트 미표시
7 선택 날짜 표시 (행 밀림)
날짜 클릭 시 해당 셀에 퍼플 보더로 선택 표시
해당 행 아래에 축제 리스트 영역이 삽입되며 행이 밀림
✕ 닫기 버튼으로 접기 가능
8 축제 카드 리스트 (가로 스크롤)
선택 날짜의 축제를 가로 카드로 표시
카드 구성: 대표이미지, 축제명, 위치, 기간, 해시태그, [상세보기]
3개 초과 시 가로 스크롤로 탐색
scroll-snap으로 자연스러운 스크롤
9 가로 스크롤 안내
"← 가로 스크롤 →" 텍스트로 사용자 안내
커스텀 스크롤바 (퍼플 계열)

Check Point

· API: GET /api/calendar?year=2026&month=3 (월별 축제 카운트)
· API: GET /api/calendar/festivals?date=2026-03-18 (일자별 축제 목록)
· 날짜 클릭 시 해당 행(주) 아래에 확장 영역 삽입, 기존 행은 아래로 밀림
· 축제 카드 3개 초과 시 overflow-x: auto로 가로 스크롤
· scroll-snap-type: x mandatory 적용
· 날짜 미선택 시 오늘 날짜 축제를 기본 표시
· [상세보기] 클릭 → /festivals/{festivalId}로 이동
