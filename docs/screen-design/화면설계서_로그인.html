Description

Summary.

  • 전국축제 플랫폼 '이음'의 통합 로그인 화면
  • 이메일 기반 자체 로그인 및 카카오/네이버 소셜 로그인 지원
  • 사용자 편의를 위한 자동 로그인 및 아이디 저장 기능 제공
1 로고 및 앱 타이틀
축제 플랫폼 브랜드 로고와 메인 타이틀 표시
서비스의 성격을 알리는 서브 타이틀 포함
2 이메일 입력 필드
사용자 이메일 계정 입력 (E-mail 형식 유효성 체크)
입력 필드 내 메일 아이콘 및 플레이스홀더 표시
3 비밀번호 입력 필드
비밀번호 입력 (8자 이상, 마스킹 처리)
우측 '눈 아이콘' 클릭 시 비밀번호 텍스트 표시/숨김 토글
4 로그인 환경 설정 및 링크
· 자동 로그인: 체크 시 세션 유지
· 아이디 저장: 로컬 스토리지에 이메일 저장
· 비밀번호 찾기: 클릭 시 계정 찾기 페이지로 이동
5 로그인 버튼
프라이머리 컬러(Blue) 버튼
클릭 시 API 통신을 통해 JWT 토큰 발급 및 메인 페이지 이동
6 소셜 로그인 영역
'또는' 텍스트를 포함한 구분선 아래에 배치
· 카카오 로그인 (Yellow)
· 네이버 로그인 (Green)
각 플랫폼 별 OAuth 2.0 연동
7 회원가입 안내
계정이 없는 사용자를 위한 회원가입 유도 텍스트
'회원가입' 클릭 시 약관 동의 및 가입 페이지 이동

Check Point

· 입력 필드 미입력 시 에러 메시지 노출 (Validation)
· 키보드 엔터(Enter) 입력 시 자동으로 로그인 버튼 동작
· 소셜 로그인 성공 시 추가 정보 입력 필요 여부 확인
· 반응형 디자인 고려 (모바일/웹 공통 레이아웃 유지)
