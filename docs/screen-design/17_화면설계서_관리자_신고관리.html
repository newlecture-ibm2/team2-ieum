Description

Summary.

  • 사용자가 신고한 콘텐츠(게시글, 댓글, 리뷰)를 관리하는 화면
  • 신고 목록 테이블 + 상세 검토 영역 제공
  • 대기중 신고 건수를 배지로 표시
  • API_ADM_0050~0052 연동
1 관리자 사이드바 네비게이션
· 현재 메뉴(신고 관리)는 파란색 활성 표시
2 페이지 타이틀 + 대기 건수 배지
· "🚨 사용자 신고 관리" 제목
· 우측에 대기중 건수 빨간 배지 표시
3 대기중 건수 배지
· status=PENDING 건수를 실시간 표시
· 빨간 배경 + 흰색 텍스트
4 신고 목록 테이블
API: GET /api/admin/reports (API_ADM_0050)
· 컬럼: 신고 대상, 신고 사유, 신고 날짜, 상태, 관리
· 상태 배지: 대기중(노란), 처리완료(녹색)
· 대기중인 건에만 [검토] [제재] 버튼 표시
· 처리완료 건은 ✅ 아이콘만 표시
5 관리 액션 버튼
· [검토] — 신고 상세 검토 영역 펼침
· [제재] — 즉시 삭제 처리 (확인 모달 후)
6 신고 상세 검토 영역
조회 API: GET /api/admin/reports/{id} (API_ADM_0051)
처리 API: PATCH /api/admin/reports/{id} (API_ADM_0052)
· [검토] 클릭 시 하단에 상세 내용 표시
· 신고 대상, 사유, 원본 콘텐츠 확인 가능
· "반려 (DISMISS)" — 신고 기각, 콘텐츠 유지
· "삭제 처리 (DELETE)" — 해당 콘텐츠 삭제
· action: DELETE 또는 DISMISS 전송

Check Point

· 관리자(ADMIN) 권한 검증 필수
· 신고 처리 시 해당 콘텐츠의 작성자에게 알림 발송 고려
· 동일 콘텐츠에 복수 신고 시 하나로 묶어서 표시
· 처리 완료 후 상태 즉시 갱신 (낙관적 업데이트)
· 대기중 건수 배지는 목록 API 응답의 PENDING 건수로 계산

API ID Method Endpoint 설명 파라미터 인증
