## 화면 유형 설명

| 유형 | 설명 |
|------|------|
| **페이지** | 독립 URL을 가진 풀 페이지 화면 |
| **영역(섹션)** | 페이지 내 특정 구역 (별도 페이지 아님) |
| **모달/팝업** | 오버레이로 표시되는 화면 |
| **드롭다운** | 헤더 등에서 토글로 열리는 영역 |
| **시스템 다이얼로그** | 브라우저 네이티브 권한 요청 등 |

## FCM 화면설계 접근법

> FCM은 독립 페이지가 아니므로 아래처럼 구분합니다:

1. **UI-FCM-001 (전체 알림 패널)**: GNB 벨 아이콘 클릭 시 드롭다운으로 알림 리스트 표시. 와이어프레임에는 헤더 영역에 마커를 붙여 설명.
2. **UI-FCM-002 (알림 설정)**: 마이페이지 > 설정 섹션 안에 "푸시 알림 ON/OFF" 토글 포함. 마이페이지 화면설계서 내 영역으로 표현.
3. **UI-FCM-003 (브라우저 권한 요청)**: 로그인 직후 또는 알림 ON 시 브라우저 네이티브 다이얼로그. 화면설계서에는 트리거 조건과 흐름만 기술.
