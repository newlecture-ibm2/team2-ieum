Description

Summary.

  • 신규 사용자가 계정을 생성하기 위한 회원가입 페이지
  • 필수 개인정보 입력 및 약관 동의 과정 수행
  • 각 입력 필드별 실시간 유효성 검사 진행
1 로고 및 타이틀 정보
· 앱 서비스 로고 표시
· "회원가입", "축제 플랫폼에 오신 것을 환영합니다" 서브 카피 표출
2 이름 입력
· 사용자 실명 입력 텍스트 필드
· Placeholder: (사람 아이콘) 홍길동
3 이메일 입력
· 아이디로 사용될 유효한 이메일 주소 입력
· Placeholder: (봉투 아이콘) example@email.com
· 이메일 형식(정규식) 실시간 검증
4 닉네임 입력
· 서비스에서 사용할 닉네임(별명) 입력 필드
· Placeholder: (사람 아이콘) 닉네임을 입력하세요
· 2~20자, 중복 불가 (실시간 중복 확인)
5 전화번호 입력
· 휴대폰 번호 입력 필드
· Placeholder: (전화 아이콘) 010-1234-5678
· 숫자만 입력 가능하며 하이픈(-) 자동 포맷 적용
6 비밀번호 입력
· Placeholder: (자물쇠 아이콘) 8자 이상, 영문+숫자 포함
· 보안 요구사항 충족 여부 실시간 안내
· 우측 눈(Eye) 아이콘 클릭 시 비밀번호 텍스트 표시/숨김 토글
7 비밀번호 재입력 (확인)
· 입력된 비밀번호와 일치하는지 확인하기 위한 필드
· 비밀번호 불일치 시 입력창 하단에 경고 메시지 출력
8 약관 전체 동의 및 개별 동의
· [전체 동의] 체크박스: 클릭 시 하위 모든 항목 상태 동기화
· [필수] 이용약관 동의
· [필수] 개인정보 처리방침 동의
· [선택] 마케팅 정보 수신 동의
9 회원가입 버튼
· 필수 입력 사항과 필수 약관 동의가 모두 완료되면 버튼 활성화(파란색)
· 미충족 시 비활성화(회색) 상태 유지
10 로그인 페이지 이동 링크
· "이미 계정이 있으신가요? 로그인"
· 이미 가입한 사용자의 경우 로그인 페이지로 이동하도록 연결
🎯 Event Description
E1 입력 필드 유효성 검사 (Realtime Validation)
· 트리거: 각 입력 필드 focus out 또는 입력 중
· 이메일: 정규식 형식 검증
· 닉네임: 2~20자 + 서버 중복 확인
· 전화번호: 숫자만 허용 + 하이픈 자동 포맷
· 비밀번호: 8자 이상 + 영문+숫자 포함 검증
· 실패 시: 빨간색 에러 메시지 + 입력창 테두리 변경
E2 비밀번호 표시/숨김 토글 (Toggle Password)
· 트리거: 눈(Eye) 아이콘 클릭
· 동작: 비밀번호/비밀번호 확인 필드의 type 속성 전환
E3 전체 동의 체크 (Toggle All Terms)
· 트리거: [전체 동의] 체크박스 클릭
· 동작: 하위 모든 약관 항목 체크/해제 동기화
E4 약관 상세 보기 (View Terms Detail)
· 트리거: 각 약관 항목 우측 > 아이콘 클릭
· 동작: 해당 약관 전문 모달 또는 새 페이지로 표시
E5 [회원가입] 버튼 클릭 (Submit Registration)
· 트리거: 회원가입 버튼 클릭
· 전제: 필수 입력 + 필수 약관 동의 완료 → 버튼 활성화(퍼플)
· 미충족 시: 버튼 비활성화(회색) 상태 유지
· 성공 시: 완료 안내 팝업 또는 메인 페이지 자동 전환
· API: POST /api/auth/signup
E6 [로그인] 링크 클릭 (Navigate to Login)
· 트리거: "이미 계정이 있으신가요? 로그인" 텍스트 클릭
· 동작: 로그인 페이지(UI-F-000)로 라우팅 이동

Check Point

· 모든 입력 필드의 유효성 검사 기준 (정규식, 공백 방지 등) 설정 필요
· 입력 오류 발생 시 빨간색 안내 문구와 입력창 테두리 색상 변경
· 회원가입 성공 시 완료 안내 팝업 또는 메인 페이지로 자동 전환
