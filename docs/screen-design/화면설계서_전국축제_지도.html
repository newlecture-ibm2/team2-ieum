Description

Summary.

  • 카카오맵 API 연동 기반의 전국 축제 지도 탐색 화면
  • 세계지도에서 한반도로 빨려들어가는 줌인 진입 애니메이션 적용
  • 시/도별 클러스터링, GPS 현위치, 인포윈도우 등 지도 인터랙션 제공
  • 좌측 사이드바 필터와 하단 목록을 통해 다차원 축제 탐색 가능
1 GNB (상단 네비게이션)
로고 "IEUM" + 메뉴 탭: 전국축제 | 지난축제 | 달력 | 커뮤니티 | 공지
우측에 검색, 알림, 로그인/닉네임 표시
전국축제 탭이 활성 상태 (파란색 밑줄)
2 탭 필터 (전체 / 진행중 / 진행전 / 🗺️ 지도)
· 현재 "지도" 탭이 활성 상태 (파란색 밑줄 하이라이트)
· 다른 탭 클릭 시 카드 리스트 뷰로 전환
· 탭 전환 시 URL의 view 쿼리 파라미터 변경
3 필터 사이드바 (좌측 패널)
· 지역 필터 — 시/도 체크박스 다중 선택
· 날짜 필터 — 시작일 ~ 종료일 범위 지정
· 상태 필터 — 전체 / 진행 예정 / 진행 중 라디오
· 카테고리 — 문화예술, 음식, 전통, 자연, 야시장 체크박스
· 검색 — 축제명 텍스트 검색
· [필터 초기화] 버튼으로 전체 리셋
필터 변경 시 지도 마커 + 하단 목록이 실시간 갱신
4 클러스터 마커 (시/도별 그룹)
· 파란색 원형 마커 안에 해당 지역 축제 갯수 표시
· 클릭 시 줌 인 → 하위 개별 마커 분리 표시
· 줌 아웃 시 다시 클러스터로 자동 병합
5 인포윈도우 (마커 클릭 시 팝업)
개별 📍 마커 클릭 시 노출되는 말풍선 팝업:
· 축제명 (굵은 텍스트)
· 📍 위치 + 📅 기간
· ⭐ 평균 별점 + 👁️ 조회수
· [상세보기 →] 링크 클릭 시 축제 상세 페이지 이동
6 GPS 현위치 + 줌 컨트롤
· 📍 현위치 버튼 — 브라우저 Geolocation API로 현재 위치 이동
· [+] / [−] 줌 버튼 — 지도 확대/축소
· 현위치 이동 시 주변 축제 마커 자동 표시
7 하단 검색 결과 목록
지도 아래 테이블 형태로 축제 리스트 표시:
· 축제 이미지 썸네일 + 축제명 + 지역 + 기간 + 별점
· 목록 항목 호버/클릭 시 해당 마커 하이라이트 + 지도 이동
· ▲/▼ 토글로 목록 열기/접기 가능
· 페이지네이션 적용 (◀ 1 2 3 4 5 ▶)
8 세계→한국 줌인 진입 애니메이션
· 페이지 최초 진입 시 세계지도가 보이다가 한반도로 자동 줌인
· 카카오맵 setCenter + setLevel API 활용
· 약 1.5~2초간의 부드러운 빨려들어가는 트랜지션 적용
· 애니메이션 완료 후 클러스터 마커 fade-in 표시

Check Point

· 카카오맵 JavaScript API 키 등록 및 CORS 설정 필수
· GPS 현위치 접근 시 브라우저 권한 허용 팝업 처리
· 클러스터 마커 클릭 → 줌인 시 부드러운 트랜지션 적용
· 인포윈도우 "상세보기" 클릭 → /festivals/{id} 라우팅
· 필터 변경 시 지도 마커 + 하단 목록 동시 실시간 갱신
· 모바일에서는 필터 사이드바를 바텀시트(Bottom Sheet)로 전환
· 비회원도 지도 조회 가능, 찜하기는 로그인 필요
