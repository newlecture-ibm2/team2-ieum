## 주요 인터랙션

| 요소 | 동작 |
|------|------|
| 프로세스 인디케이터 | 현재 진행 중인 단계(이메일 입력 > 인증 확인 > 비밀번호 재설정)를 시각적으로 표시 |
| 이메일 입력창 | 사용자가 가입했던 이메일 입력 (이메일 정규식 유효성 검사 적용) |
| 인증 코드 받기 버튼 | 입력된 이메일이 유효할 경우 활성화되며, 클릭 시 인증 메일 전송 및 다음 단계(인증 확인)로 이동 |
| 로그인으로 돌아가기 | 클릭 시 `02. 로그인` 화면으로 리다이렉트 (이전 단계 복귀) |
| 홈으로 돌아가기 | 클릭 시 메인 랜딩 페이지(`01. 메인페이지`)로 이동 |
