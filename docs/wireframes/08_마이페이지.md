## 주요 인터랙션

| 요소          | 동작                              |
| ------------- | --------------------------------- |
| 좌측 메뉴     | 즐겨찾기/게시글/리뷰/댓글/문의/알림설정 탭 전환 |
| 즐겨찾기 해제 | 즐겨찾기 목록에서 즉시 제거       |
| 카드/글 클릭  | → 해당 축제/게시글/리뷰/문의 상세 페이지 이동 |
| 프로필 수정   | 이미지 업로드 + 닉네임 변경       |
| 회원 탈퇴     | 탈퇴 진행 팝업 노출               |
| 게시글/댓글   | 링크 이동 시 해당 글 수정/삭제 가능 |
| 삭제 동작     | 삭제 시 확인 팝업 발생. 본 문서 삭제 시 연관된 하위 댓글 및 답글 모두 숨김 처리 (답글 작성자의 페이지에서도 노출되지 않도록 처리) |
