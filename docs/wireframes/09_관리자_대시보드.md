| 메뉴 | 화면 | 담당자 | 관련 API |
|------|------|--------|---------|

## 주요 인터랙션

| 요소 | 동작 |
|------|------|
| 사이드바 메뉴 | 각 관리 페이지 전환 (활성 메뉴 하이라이트) |
| 공공 API 수동 갱신 | data.go.kr API 호출 → 축제 데이터 동기화 + 결과 표시 |
| 축제 등록 버튼 | 자체 기획 축제 등록 모달/폼 진입 |
| 신고 검토/제재 | 대기 → 처리완료/기각 상태 변경, 해당 콘텐츠 삭제/유지 |
| 공지 팝업 설정 | 메인 페이지 팝업 노출 여부 설정 |
| 문의 답변 | 문의 상세 열림 + 답변 작성 폼 |
| 축제 노출/숨김 | 공공 축제 목록에서 isVisible 토글 |
