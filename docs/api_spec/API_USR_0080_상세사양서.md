## 5. 처리 Logic

3. 최신 접수일(`createdAt DESC`) 순으로 정렬하여 결과를 가져온다. ⚙️
4. 조회된 리스트 데이터와 함께 페이징 관련 메타 데이터(전체 건수 등)를 JSON 형태로 구성하여 반환한다. ✨🚀
