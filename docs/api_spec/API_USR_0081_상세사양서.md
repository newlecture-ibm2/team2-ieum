## 5. 처리 Logic

1. 경로 변수인 `reportId`를 파라미터로 전달받는다. 🛰️
2. `reports` 테이블에서 해당 ID로 조회하되, 현재 로그인한 사용자의 ID(`reporterId`)가 일치하는지 반드시 검증한다. (본인이 아닌 경우 403 에러) 🛡️🏛️
3. 신고 정보와 함께 관리자가 수정한 처리 피드백(`adminNote`, `processedAt`, `actionType`) 데이터를 함께 추출한다. ⚙️
4. 만약 아직 처리가 되지 않은 상태(`PENDING`)라면 관리자 관련 필드는 `null` 또는 비어있는 상태로 반환한다. 🛠️
5. 조회된 상세 데이터를 JSON 형식으로 매핑하여 최종 응답한다. ✨🚀
