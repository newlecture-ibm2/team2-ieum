## 2. 기능 요건
1. 로그인한 사용자가 서비스 이용 중 발생하는 불편사항이나 질문을 1:1 문의로 등록한다. ✍️
2. 문의 내용(제목, 내용, 카테고리)을 필수적으로 입력받아 DB에 저장한다. 🛡️
3. 등록 시 처리 상태는 기본값인 `PENDING` (대기 중)으로 설정된다. ✨

## 5. 처리 Logic

1. 클라이언트로부터 `JSON` 요청 본문을 통해 문의 유형, 제목, 내용을 전달받는다. 🛰️
2. 입력값의 누락 여부를 검증하고(필수값 미입력 시 400 에러), **제목은 최대 50자, 내용은 최대 2000자**로 제한한다. (초과 시 400 에러 반환) 🛡️
3. SecurityContext에서 로그인한 사용자의 ID를 추출하여 작성자 정보로 활용한다. 🏛️
4. `inquiries` 테이블에 `author_id`, `type`, `title`, `content`를 저장하고, `status`는 `PENDING`으로 기본 할당한다. ✨⚙️
5. 등록 완료 후 생성된 `inquiryId`를 포함한 성공 응답을 반환한다. 🚀
