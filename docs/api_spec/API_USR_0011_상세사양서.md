## 2. 기능 요건
1. 사용자의 프로필 이미지를 서버에 업로드하고 해당 경로를 DB에 갱신한다. 🖼️
2. 이미지 파일 형식(JPG, PNG) 및 용량 제한(5MB)을 검증한다. 🛡️
3. 성공 시 업데이트된 이미지 URL을 반환한다. ✨

## 5. 처리 Logic

1. 클라이언트로부터 `multipart/form-data` 형식으로 `profileImg` 파일을 전달받는다. 🛰️
2. 파일 확장자가 이미지 형태(jpg, jpeg, png)인지 확인하고, 파일 사이즈가 5MB를 초과하는지 검증한다. (위반 시 400 에러) 🛡️
3. 유효한 파일인 경우, 서버의 전용 스토리지 경로(예: `/uploads/profiles/`)에 고유한 파일명(UUID)으로 저장한다. ⚙️
4. SecurityContext에서 로그인한 사용자의 ID를 추출하여 `users` 테이블의 `profile_image` 컬럼값을 위 저장된 경로로 `UPDATE`한다. 🏛️
5. 최종적으로 저장된 `imageUrl`과 성공 메시지를 JSON 형태로 반환한다. ✨🚀
